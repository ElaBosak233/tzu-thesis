# 正文排版检查

检查日期：2026-10-20。以实际长篇论文的副本作为压力样本，检查公式、深层标题、图表、题注和分页。修复位于 `templates/common/styles.typ`，论文与文献综述共用。

## 发现与修复

| 项目 | 原有表现 | 当前规则 |
| --- | --- | --- |
| 连续独立公式 | 三条密钥派生公式的基线距离约 10.53pt，几乎没有空隙 | 公式块上下各留 15.6pt；相邻块的留白折叠为较大值，这组公式的基线距离约 26.13pt |
| 单个公式内的多行推导 | 继承正文的 `par.leading: 0pt`，各行可能贴在一起 | 仅对块级公式设置 15.6pt 行间留白；分式、根式、求和与上下标按自然高度占位 |
| 连续图表与前后正文 | 外侧间距随正文零段距归零，下一幅图或表题紧贴上一块 | 图表块上下各留 7.8pt；内部题注间距继续为 7.8pt |
| 四级及更深标题 | 只有一至三级被明确配置，深层标题缺少编号并使用默认段距 | 编号继续为 `1.1.1.1` 等层级形式；字体、字号、行框与段前后距离沿用该材料的三级标题规则 |

普通段落使用完整的 23.4pt 行框，因此其额外行距和段距为零。公式按自然数学高度排版，不能依赖这个零段距来区分相邻公式；多行公式的行间留白也需要单独恢复。Typst 支持[通过 block 设置块级元素的前后间距](https://typst.app/docs/reference/layout/block/#parameters-spacing)，相邻块取较大的间距；[0.14.2 的公式排版实现](https://github.com/typst/typst/blob/v0.14.2/crates/typst-layout/src/math/run.rs)使用 `par.leading` 分隔多行公式。

这些块级留白和四级标题规则是本次补充的模板规则。原 Word 校准覆盖一至三级标题和普通段落，没有给出四级标题的独立规格，也没有据此测得上述公式留白。四级标题在论文中使用五号，在综述中沿用三级标题的小四号；目录仍默认收录至三级。

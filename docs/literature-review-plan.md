# 文献综述模板

状态：已实现，2026-10-19 经 Microsoft Word 原版 PDF 校准。编辑根目录 `literature-review.typ` 即可使用，现有 `main.typ` 与 `thesis.with(...)` 继续有效。

## 参考与证据

参考原件：`04. 文献综述模板及基本要求（务必按此模板写）.doc`，2027 届材料目录。

SHA-256：`faeaf8fe8e2b3e080e9f6427ce88bd403255b151d1c77992a32111f4f2bca2eb`。

原件保持不变。初步以 textutil 和 LibreOffice 检查文字与格式，最终在 Microsoft Word for Mac 16.113.3 中保存保留兼容性设置的 DOCX 副本并导出 PDF。另在该副本中保留网格，制作不同字体字号的三行校准段落，由 Word 导出 PDF 测量基线。最终数值取自 Word，不采用 LibreOffice 的渲染结果。

文档中的填写示例、说明气泡和“以下内容仅供参考”后面的写作指导是参考资料，不是要自动插入综述的内容。格式说明与示例的局部格式存在冲突，实施时分别记录，不直接复制全部直接格式。

## 输出结构

文献综述应独立生成一个 PDF：

1. 首页题名：`“毕业设计题目”文献综述`。
2. 学生姓名、指导教师信息。
3. 同页中文摘要和关键词。
4. 编号正文，一至三级标题按原版校准，四级及更深标题沿用三级样式并继续编号。
5. 另起一页的参考文献，允许列表继续跨页。

沿用原版的页眉文字“人工智能学院毕业设计文献综述”和阿拉伯页码。原版未展示独立封面、授权书、英文摘要、目录、谢辞和承诺书，综述模板不生成这些页面。

## 共用项与模板差异

| 项目 | 现有论文 | 文献综述的原版要求 |
| --- | --- | --- |
| 正文字体 | 宋体五号，西文 Times New Roman | 宋体五号，西文采用对应统一规则 |
| 正文段落 | 两端对齐、首行缩进两字 | 可共用；原件普通样式为两端对齐，正文存在两字缩进 |
| 正文行距 | 已按论文原件校准为 23.4pt | 1.5 倍，保留网格的 Word 实测同为 23.4pt |
| 首页题名 | 中文题名、英文题名等 | 黑体三号 16pt，1.5 倍，段前两行、段后一行 |
| 作者信息 | 学院、专业、姓名、导师多行 | 学生姓名、指导教师同一行，楷体五号，1.5 倍，段前后各一行 |
| 摘要和关键词 | 独立摘要页，小四号 | 与正文同页，标签黑体五号，内容宋体五号，1.5 倍，段前后零 |
| 一级标题 | 黑体四号，已校准行高 31.2pt | 黑体四号 14pt，单倍，段前后各一行 |
| 二级标题 | 黑体小四号 | 黑体小四号 12pt，1.5 倍，段前后各半行 |
| 三级标题 | 黑体五号 10.5pt | 黑体小四号 12pt，1.5 倍，段前后各半行 |
| 参考文献 | 独立页，小五号单倍 | 独立页，小五号 9pt 单倍；标题黑体小四号，1.5 倍，段前后各 1.5 行 |
| 页眉 | 当前论文模板不显示固定页眉 | 人工智能学院毕业设计文献综述 |

综述上边距为 1588 twips（79.4pt，约 2.8cm），与论文的 2.5cm 不同；左边距约 3cm，右、下各约 2.5cm。已由 Word 副本的节属性及 PDF 位置复核，综述独立设置页面参数。原件页眉距纸边约 1.5cm，页脚距纸边约 1.75cm；模板再按文字基线与横线位置校准。

原件示例存在直接格式覆盖，例如二级标题的样式字号与其文字的直接字号不同。综述模板按格式说明明确设置三级标题字号；黑体与是否额外加粗分别配置，继续保留伪粗体能力。

## 接口与代码组织

论文与综述按材料类型分别提供 `thesis` 和 `literature-review` 入口，各自负责页面编排；共用规则放在 `templates/common/`。完整职责和旧路径迁移见[模板目录说明](template-structure.md)。

文件组织：

```text
literature-review.typ              # 综述写作与编译入口
ref.bib                            # 可由两份材料共用
main.typ                           # 论文写作与编译入口

templates/
  thesis/
    lib.typ                        # 论文编排与内容接口
    pages/                         # 论文专属页面
  literature-review/
    lib.typ                        # 综述编排和特有样式
  common/
    styles.typ                     # 共用正文、标题、图表和引用样式
    fonts.typ                      # 共用字体、字号
    layout.typ                     # 共用行框等工具，分别传入校准值
    bibliography.typ               # 共用参考文献排版
    utils.typ                      # 共用引用、表格等工具
    patches.typ                    # 列表排版补丁工具
```

最小用法（题名只填写题目本身，外层引号和“文献综述”会自动添加）：

```typ
#import "templates/literature-review/lib.typ": literature-review

#show: literature-review.with(
  title: "毕业设计题目",
  student: "张三",
  advisor: "李四",
  abstract: [在此填写综述摘要。],
  keywords: ("关键词一", "关键词二", "关键词三"),
  bibliography: bibliography.with("ref.bib"),
)

= 引言
在此填写正文，并引用自己的文献，例如 @cai2021densenet。

= 国内外研究现状
在此填写正文。

== 主要研究方向
在此填写正文。

= 现有问题与发展趋势
在此填写正文。
```

共享作者信息用普通字典传参即可，不引入跨文档的全局状态。两份入口各自编译，分别拥有页码、标题、图表和引用编号。共用 `ref.bib` 不表示把整个文献库全部列出，默认按各材料实际引用生成各自的参考文献列表。

共用样式在 `templates/common/styles.typ`，综述传入三级标题为 12pt 的覆盖值；论文维持 10.5pt。综述特有的首页摘要通过 `abstract: [...]` 直接传入，不调用生成独立页面的 `abstract-page()`。题名与摘要均在正常文档流内，长题名可以换行，长摘要可以继续分页。

独立公式、多行公式及图表的留白由共用正文样式明确设置，四级及更深标题继续使用综述三级标题的小四号；这些补充规则和回归检查见[正文排版检查](body-layout-audit.md)。

引用和图表复用论文规则：引用为顺序编码上标，`parencite` 可生成正文内引用；图表在章内共享序号，表题在上、图题在下。这些是项目默认，综述原件没有单独明确规定。伪粗体仍由 `cuti` 提供，正文强调和摘要标签可继续加粗；不对原件要求常规字重的黑体标题统一额外加粗。

## 参数与编译

| 参数 | 用法 |
| --- | --- |
| `title`、`student`、`advisor` | 字符串，填写题目、姓名和导师 |
| `second-advisor` | 默认 `none`；填写后与第一导师以顿号分隔 |
| `abstract` | Typst 内容块，与首页正文连续排版 |
| `keywords` | 包含 3–6 项的数组，以中文分号连接 |
| `header` | 默认“人工智能学院毕业设计文献综述”，可按实际学院修改 |
| `bibliography` | 必填，例如 `bibliography.with("ref.bib")` |
| `bibliography-full` | 默认 `false`，只列实际引用；排版示例设为 `true` |
| `bibliography-style` | 默认 `"gb-7714-2015-numeric"` |

```sh
typst compile --ignore-system-fonts --font-path assets/fonts main.typ dist/main.pdf
typst compile --ignore-system-fonts --font-path assets/fonts literature-review.typ dist/literature-review.pdf
typst compile --root . --ignore-system-fonts --font-path assets/fonts tests/line-spacing.typ dist/line-spacing-test.pdf
typst compile --root . --ignore-system-fonts --font-path assets/fonts tests/literature-review.typ dist/literature-review-test.pdf
python3 tests/check-literature-review.py
```

PDF 集成检查依赖 Python 的 `pdfplumber`（可用 `python3 -m pip install pdfplumber` 安装），模板编译只需要 Typst。`--ignore-system-fonts` 让校准使用仓库内字体；日常也可以省略此项。

## 校准与验收结果

Word 原件保留 `linePitch="312"` 的 15.6pt 网格。三号黑体题名实测行高 31.2pt；五号楷体、五号宋体和小四号黑体的 1.5 倍行距为 23.4pt；小五号宋体单倍为 15.6pt。**四号黑体一级标题即使是单倍，Word 实测仍为 31.2pt**，因此没有按单倍字面含义缩成 15.6pt。

已编译论文与综述；共用样式抽取前后，原论文 11 页的文字、字号及位置（精确到 0.001pt）一致。集成检查覆盖 Word 基线、页眉横线、连续页码、长题名、跨页摘要、正文引用与图表，以及 40 条测试文献的跨页列表和错误参数提示。测试条目仅在临时目录生成，不进入实际文献库。

两种排版引擎在断行、标点挤压、两端对齐和浮动图表处理上仍有差别；这组值针对这份 2027 原版，不作为通用的 Word 倍数行距换算。示例参考文献使用项目已有文献库，内容与 Word 原件不同，对照时主要看字号、行距和位置。其他材料应取得对应原版后再添加模板。

## 内容要求与排版的边界

原件还要求综述 1500 字以上、参考文献不少于 20 篇、关键词 3–6 个，并要求收集阅读至少两篇外文原文文献，主体包括研究历史、研究现状和发展趋势。

这些要求写进使用说明。关键词数量可以直接检查；字数统计口径、实际列出的文献数量和外文原文阅读情况要分别处理，不按 Bib 文件总条目数或是否含汉字粗略判定合格。不自动填充正文或补造文献以满足数量。第一版不因示例未达到成稿数量而阻止排版预览；后续如增加提交检查，应与正常编译分开。

# 2027 Word 原版排版校准

校准日期：2026-10-19。参考文件为用户提供的 `000毕业设计正文格式模板（2027更新-务必按此模板写）.doc`。

参考文件 SHA-256：`0c62a3edca3cc46c9c24d0cf48e5fa82ad4ebd840755afb8e482edc666791365`。

## 如何取得参考值

原文件保持不变。在 Microsoft Word for Mac 16.113.3 中打开原文件，将保留兼容性模式的副本保存为 DOCX，再由 Word 本地导出 PDF。测量 PDF 中文字的基线坐标，并检查 DOCX 的段落、样式和节属性。LibreOffice 的转换只用于最初检查，最终校准值取自 Word。

另用保留原文档网格和兼容性设置的临时样本，分别检查纯中文、中英混排、不同字号及关闭网格后的行距。样本的段前段后均为 0，三行相邻段落用于测量。Word 的 PDF 坐标存在约 0.24pt 的取整，23.4pt 的间距会表现为交替的 23.28pt / 23.52pt；下表使用跨两行的平均值。

## 关键发现

原版正文的 `w:spacing` 是 `line="360" lineRule="auto"`，即 Word 的 1.5 倍行距；各节还保留了 `w:docGrid linePitch="312"`，网格节距为 **15.6pt**。不能只根据字号或字体自然行高换算。

| 部位 | 说明中要求的字体、字号 | Word 样本基线距离 | Typst 校准值 |
| --- | --- | ---: | ---: |
| 正文（纯中文及中英混排） | 宋体，五号 10.5pt | 23.4pt | 23.4pt |
| 中文摘要、英文摘要 | 宋体 / Times New Roman，小四 12pt | 23.4pt | 23.4pt |
| 二、三级标题 | 黑体，12pt / 10.5pt | 23.4pt | 23.4pt |
| 一级标题 | 黑体，四号 14pt | 31.2pt | 31.2pt |
| 学院、专业、姓名、导师 | 楷体，小五 9pt | 23.4pt | 23.4pt |
| 参考文献 | 宋体，小五 9pt，单倍行距 | 15.6pt | 15.6pt |
| 授权书正文 | 13pt，固定值 24pt | 24pt（段落属性） | 24pt |
| 诚信承诺书正文 | 仿宋，三号 16pt | 31.2pt（Word 有字体替代） | 31.2pt |

关闭网格的五号字校准样本约为 20.52pt；这进一步说明 **23.4pt 是这份原版的结果，不是所有 Word 文档的通用结果**。

旧模板的 `leading: 1.25em` 配合字体 ascender / descender 边界，五号纯中文基线距离为 23.625pt，中英混排约为 24.41pt。纯中文已经接近原版，但混排时会随字体行框变宽。

## Typst 的实现

`templates/common/layout.typ` 集中保存校准值。普通文本使用固定总行框：

```typ
top-edge: height / 2 + 0.34em
bottom-edge: -height / 2 + 0.34em
```

上下边界之差正好等于目标行高，再将 `par.leading`、`par.spacing` 设为 0。行框中已包含行间留白，所以这里的 0 并不表示文字贴在一起。新段落与段内换行使用相同节奏，对应原版段前段后均为 0。

`0.34em` 决定字形在行框中的垂直位置，是对原版的近似校准；行框总高则是精确值。上标使用字形边界，以免引用继承完整行框而增高。较高的行内公式、图片或另设边界的内容仍可能撑高行框，不把复杂内容强制裁切。

独立公式与图表另设块级留白：公式前后各 15.6pt，公式内部多行之间留 15.6pt；图表前后各 7.8pt，题注内部间距为 7.8pt。这些是实际长篇样本检查后补充的模板规则，不能从正文的零额外段距推导；依据与回归检查见[正文排版检查](body-layout-audit.md)。

目录引导点需要以基线作为下边界，因此目录单独使用 12pt 行框及 11.4pt 行间补偿，条目基线间距仍为 23.4pt。目录页首另补偿 4.2pt，使第一条目的位置接近原版。目录保留自动页码、层级缩进和内部链接。

其余调整：

- 页边距仍为上 / 下 / 右 2.5cm、左 3cm；预留页眉距纸边 1.5cm。页脚按原版的位置校准，阿拉伯页码使用 Times New Roman 12pt，罗马页码 9pt 并提高 6pt。
- 一级标题段前后各 15.6pt；二、三级标题段前后各 7.8pt，替代随字号变化的 `em` 留白。保留标题与后续内容的粘连。
- 摘要、目录、参考文献、谢辞、诚信承诺书的标题独立设定字体与字号，避免继承正文一级标题样式。
- 图表题注使用五号字、编号与题目之间空 2em；表题在上、图题在下。保留原模板图表共享的章内编号，与原版的“表 2-1 / 图 2-2”示例一致。
- 三线表内部使用 15.6pt 的单倍基线距离，并调整单元格留白。
- 正文首页导师信息会显示第二指导教师，以顿号分隔。
- 新增 `graduation-year` 参数，示例设为 2027。未指定时仍沿用完成日期的年份，完成日期和届别可以分别设置。

## 对齐与封面

原版 Normal 样式为 `w:jc="both"`。正文和摘要使用 `justify: true`，正文首行缩进为 `(amount: 2em, all: true)`，包括紧接标题后的第一段。段落末行按左对齐排列，不采用末行也拉伸的分散对齐。标题、目录、题注、表格和封面分别设置对齐，不能在全文末尾再统一启用两端对齐。

原版 `word/settings.xml` 中没有 `w:autoHyphenation`；依照 [Open XML 定义](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.autohyphenation)，这表示不自动断词。Typst 对已知语言的两端对齐段落默认可自动断词，所以普通段落还明确使用 `text(hyphenate: false)`，使英文摘要和英文单词的处理更接近原版。[Typst 对齐说明](https://typst.app/docs/reference/model/par/#parameters-justify)。

封面独立关闭两端对齐和首行缩进，使用单页区域固定校徽、校名、题名及届别的位置。继续使用项目中的校徽图片和校名 SVG。信息栏按原版使用宋体标签、楷体中文填写内容和 Times New Roman 西文，字号统一为三号 16pt，填写内容在各自下划线内居中。

第二导师标签为六字，其下划线起点单独后移；不填写第二导师时删除整行。长题目仍以 16pt 换行并增加该行高度，“题目”标签与标题末行共用基线，横线保持在该基线下方 2.28pt，其余字段顺延；这时信息栏下半部会随实际内容移动，不再保持单行示例的固定纵坐标。封面说明气泡和提示框不属于填写后的封面内容，没有复制。

## 说明与限制

原版包含红蓝说明文字、文本框和局部直接格式，有些与旁边说明不一致。本次按说明中的字体、字号统一样式，以正常文本的 Word 输出校准行高，不复制示例中的误设格式、说明框或字体替代。例如，本机 Word 将承诺书的仿宋替换成微软雅黑；Typst 使用项目自带的仿宋，因此不会复刻该字体替代导致的换行。

摘要的字数说明存在 300 / 500 字的冲突；这里没有据此更改用户的内容。原版的可选 AI 工具使用申明页也没有自动填写或插入，是否需要该页及其内容应由作者按实际情况确定。

本次完成的是排版校准，**不承诺与 Word 逐字逐页相同**。两套引擎在断行、标点挤压、两端对齐、网格字符宽度、浮动图表及高公式的处理上仍有差异。字号或字体改变后也应重新检查，不应把这组参数当作通用 Word 转换器。

## 验证方法

```sh
typst compile --font-path assets/fonts main.typ dist/main.pdf
typst compile --root . --font-path assets/fonts tests/line-spacing.typ dist/line-spacing-test.pdf
python3 tests/check-cover.py
```

行距检查覆盖宋体、中英混排、Times New Roman、黑体及仿宋的八组字体字号组合，同时检查强制换行、自动换行、新段落、上标和简单行内公式。另编译长标题、多段正文及未提供第二导师的变体，并检查生成 PDF 的页码、目录链接和文字位置。

封面对齐检查依赖 Python 的 `pdfplumber`，覆盖单行、两行和三行题目，以及未填写第二导师的情况，检查题目标签基线、横线位置和后续字段顺延。

Typst 的概念定义可参考[段落行距文档](https://typst.app/docs/reference/model/par/#parameters-leading)；Word 倍数行距属性可参考[微软 Open XML 说明](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.spacingbetweenlines.line)。
